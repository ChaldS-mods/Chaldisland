# Island: расширение для Chrome

Без расширения Island угадывает загрузки по файлам `.crdownload` в папке «Загрузки»: имени нет («файл из браузера»), общий размер неизвестен.
С расширением в карточке видно настоящее имя, размер, процент, скорость, сайт-источник и паузу.

## Установка
1. Запусти Island.
2. В Chrome открой `chrome://extensions` и включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери эту папку (`chrome-extension`).

Работает так же в Edge, Brave, Opera и Яндекс Браузере (`edge://extensions`, `brave://extensions` и т. д.).

## Как это устроено
Расширение каждые полсекунды, пока что-то качается, отправляет состояние загрузок на `http://127.0.0.1:47821/dl`.
Остров слушает только локальный адрес и принимает запросы с заголовком `X-Island` и без чужого `Origin`, то есть обычная веб-страница ему ничего отправить не сможет.
Если Island не запущен, расширение молча ничего не делает.
